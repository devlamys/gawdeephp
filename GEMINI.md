# Project Guidelines & Design Standards (GEMINI)

This project (`gawdeephp`) contains project-specific skills and design rules to guide all model interactions and code generations.

## Workspace Skills

The following skills are available within `.agents/skills/` and `.opencode/skills/`:

1. **frontend-design-system**: Design tokens, fluid typography, dark/light theme systems, CSS Grid layout patterns, and modern elevation depth.
2. **ui-ux-micro-interactions**: Performant 60fps micro-animations, skeleton screen loaders, toast notifications, scroll-driven triggers, and transition easing.
3. **responsive-ecommerce-ui**: E-commerce component patterns (product cards, cart drawers, PDP swatches, checkout UI, mobile action bar).
4. **a11y-modern-web**: Web accessibility, ARIA patterns, keyboard focus rings, focus traps, and WCAG AA contrast compliance.

## Guidelines

- All skills and rule definitions are project-local to `gawdeephp`.
- Always prefer modern, vibrant, high-contrast UI design over basic default elements.
