# Project Design & Agent Instructions

This repository (`gawdeephp`) utilizes modern frontend design standards, e-commerce UX best practices, and progressive agent skills.

## Installed Project Skills

- [frontend-design-system](file:///.agents/skills/frontend-design-system/SKILL.md): Core aesthetics, color palettes, fluid typography, glassmorphism, depth, and CSS Grid/Flex layout architecture.
- [ui-ux-micro-interactions](file:///.agents/skills/ui-ux-micro-interactions/SKILL.md): 60fps micro-animations, interaction feedback, scroll reveals, skeleton loaders, and easing curves.
- [responsive-ecommerce-ui](file:///.agents/skills/responsive-ecommerce-ui/SKILL.md): E-commerce components (product grids, sliding cart drawer, PDP, quick view, mobile navigation, asset optimization).
- [a11y-modern-web](file:///.agents/skills/a11y-modern-web/SKILL.md): WCAG 2.1 AA compliance, focus rings, keyboard traps, ARIA live regions, and semantic HTML5.

## Core Rules for Frontend Work

1. **Scope Limit**: All styling, script modifications, and skill additions must remain strictly scoped to this project directory (`gawdeephp`). No global configuration changes.
2. **Visual Quality**: Never build low-fidelity MVP designs. Always use rich color tokens, subtle depth, smooth hover effects, and responsive mobile layouts.
3. **Accessibility**: All interactive elements must maintain a minimum `44x44px` touch area and a visible `:focus-visible` ring.
